# منصة التواصل الأكاديمي عبر الواتساب - جامعة برج العرب التكنولوجية

منصة أكاديمية متكاملة تهدف إلى ربط الطلاب بأعضاء هيئة التدريس والهيئة المعاونة في جامعة برج العرب التكنولوجية عبر جسر آمن يعتمد على تطبيق الواتساب (WhatsApp Web Bridge)، مع الحفاظ التام على خصوصية وتشفير أرقام هواتف المحاضرين باستخدام خوارزميات AES-256-GCM.

---

## نظرة عامة على المشروع

توفر المنصة بيئة تواصل موحدة وسريعة بين الطالب وأعضاء هيئة التدريس:
- يقوم الطالب بتصفح دليل الكادر الأكاديمي بحسب القسم وتوجيه الاستفسارات الدراسية.
- يتم إرسال السؤال تلقائياً إلى واتساب الدكتور عبر المحاكي المدمج في النظام دون كشف رقم هاتف الدكتور للطالب.
- يتلقى الطالب الرد مباشرة في الواجهة مع دعم التحديث المباشر عبر الإشعارات وتكنولوجيا الإشارات الحية (WebSockets).

---

## الهيكل التقني للمشروع (Tech Stack)

### 1. الواجهة الأمامية (Frontend)
- **الإطار**: React 19 + Vite 6
- **التصميم**: Vanilla CSS + Tailwind CSS 3.4
- **الأيقونات**: Lucide React
- **الاتصال المباشر**: Socket.io Client (Real-time updates)
- **الإشعارات**: Web Push Notifications (Service Worker)

### 2. الخلفية (Backend)
- **البيئة**: Node.js + Express.js
- **قاعدة البيانات**: SQLite عبر Prisma ORM
- **ربط الواتساب**: Whiskeysockets Baileys Engine (WhatsApp Web API Bridge)
- **التشفير والعدل الأمني**: 
  - AES-256-GCM لتشفير أرقام الهواتف
  - Bcrypt.js لتشفير كلمات المرور
  - JSON Web Token (JWT) للمصادقة وحماية الجلسات

---

## بنية البيانات (Database Schema)

تعتمد المنصة على الجداول التالية في Prisma ORM:

- **User**: حسابات المستخدمين (طلاب، مشرفين، مدراء نظام Super Admin).
- **Doctor**: بيانات الكادر الأكاديمي (الاسم، التخصص، القسم، المواد، الرقم المشفر).
- **Department**: الأقسام الأكاديمية (الدكاترة، المعيدين، شؤون الطلبة، الإدارة).
- **Conversation**: المحادثات الأكاديمية بين الطالب والدكتور كود مرجعي فريد (مثل REQ-1042).
- **Message**: الرسائل المتبادلة وتدعم المرفقات (الصوت، الصور، المستندات).
- **PushSubscription & Notification**: نظام إشعارات المتصفح والردود الفورية.

## كيفية تشغيل المشروع محلياً (Local Setup & Running)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### 1. تثبيت الاعتمادات (Dependencies)

**تثبيت مكتبات الخلفية (Backend):**
```bash
cd backend
npm install
```

**تثبيت مكتبات الواجهة الأمامية (Frontend):**
```bash
cd frontend
npm install
```

---

### 2. تجهيز قاعدة البيانات وتشغيل الحسابات الافتراضية

في مجلد `backend`:
```bash
npx prisma db push
node seed_test_accounts.js
```

---

### 3. تشغيل الخوادم (Development Servers)

**تشغيل خادم الخلفية (Backend API on http://localhost:5000):**
```bash
cd backend
npm run dev
```

**تشغيل خادم الواجهة الأمامية (Frontend Web App on http://localhost:3000):**
```bash
cd frontend
npm run dev
```

## المميزات الرئيسية للمنصة

### لجانب الطلاب
1. تصفح دليل أعضاء هيئة التدريس والمعيدين بحسب القسم أو عبر محرك البحث.
2. إرسال استفسارات أكاديمية وإرفاق مقاطع صوتية وصور ومستندات.
3. متابعة حالة المحادثة (مفتوحة، تم الرد، مغلقة) مع كود مرجعي لكل سؤال.
4. تلقي إشعارات حية وتحديثات فورية فور رد المحاضر.

### لجانب الإدارة والمشرفين
1. لوحة تحكم شاملة لإدارة أعضاء هيئة التدريس إضافة وتعديل وتجميد.
2. تشفير أرقام الهواتف تلقائياً بـ AES-256 لحماية الخصوصية.
3. تصدير واستيراد بيانات الدكاترة دفعة واحدة عبر ملفات Excel / CSV.
4. محاكي رسائل اختبار وتأكيد حالة ربط محرك الواتساب (Baileys Status).
5. إدارة المشرفين الفرعيين وتحديد الصلاحيات المخصصة لكل مشرف.

## الأمان والخصوصية (Security & Safeguards)

- عدم كشف رقم هاتف الدكتور في أي استجابة API موجهة للطلاب.
- حماية مسارات المشرفين باستخدام JWT Middlewares المخصصة.
- حماية الاستعلامات من هجمات SQL Injection عبر Prisma ORM.
- تفعيل رؤوس الأمان (Security Headers) مثل `X-Content-Type-Options` و `X-Frame-Options`.
